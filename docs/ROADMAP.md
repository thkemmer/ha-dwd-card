# HA DWD Card Roadmap

This document outlines the planned features and improvements for the `ha-dwd-card` project. Items are added here after a successful brainstorming phase.

## 🟢 Currently Developing / Testing
- **Refinement of Pollen Card:** Improving icon mapping and layout (v1.1.x series).

## 🟡 Planned Features (Ready for Phase 1)
- **Pollen Details Card:** A more detailed view of pollen forecasts (similar to the weather details card).
- **Multi-Entity Support for Warnings:** Displaying warnings for multiple regions in a single overview.

## ⚪ Idea Backlog (Brainstorming Needed)
- **Weather Map Integration:** Visualizing warnings on a local map.
- **Push Notification Configurator:** Assisting users in setting up notifications for DWD warnings.
- **Custom Icon Support:** Allow users to override default icons via configuration.

---
*To suggest a new feature, please use our [GitHub Feature Idea Template](https://github.com/thkemmer/ha-dwd-card/issues/new/choose).*
